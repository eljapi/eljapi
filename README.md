# Hola, soy Felipe

Soy ingeniero de software con una inclinación natural hacia los problemas difíciles. Lo que más disfruto del desarrollo no es escribir código, es pensar: entender un dominio, descomponerlo, y construir algo que funcione de verdad. Por eso siempre estoy explorando tecnologías nuevas, no para coleccionar herramientas, sino para entender cómo funcionan las cosas por dentro.

Tengo experiencia en fintech, en un proyecto Scada para un observatorio astronómico, y hoy llevo mi propia software factory ([SolidCore](https://solidcore.cl)) donde participo en todas las etapas: desde la licitación hasta el soporte. Trabajo con clientes privados y públicos.

## Proyectos de exploración

Estos son proyectos que hice por curiosidad, para entender algo desde adentro:

- [`sii-rag-explorer`](https://github.com/eljapi/sii-rag-explorer) — RAG sobre el FAQ del SII. Embeddings multilingües, búsqueda híbrida, LLM local.
- [`cuda`](https://github.com/eljapi/cuda) — Investigación práctica de programación en GPU con CUDA.
- [`neural-networks`](https://github.com/eljapi/neural-networks) — Desde redes densas hasta CNN y LSTM, implementadas desde cero.
- [`book-ares`](https://github.com/eljapi/book-ares) — Sistema distribuido en Go. Inspirado en Ares, pero para libros.
- [`nurse-scheduling-problem`](https://github.com/eljapi/nurse-scheduling-problem) — Optimización de turnos de enfermería en C++.
